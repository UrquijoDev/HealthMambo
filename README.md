# HealthMambo - Sistema de Gestión Clínica Integrado

## 📋 Descripción del Proyecto

**HealthMambo** es un sistema de gestión clínica de código abierto desarrollado específicamente para clínicas de fisioterapia en entornos con recursos limitados. El sistema integra la gestión de asistencia del personal y el agendamiento de citas médicas en una plataforma unificada.

### 🎯 Objetivo Principal
Evaluar y optimizar el desempeño de un sistema de código abierto para mejorar la eficiencia operativa, satisfacción de usuarios y calidad del servicio en clínicas del municipio de Empalme, Sonora.

## ✨ Características Principales

- **Gestión Integrada**: Control de asistencia del personal y agendamiento de citas en una sola plataforma
- **Código Abierto**: Sin costos de licencia, completamente personalizable
- **Diseño Responsivo**: Interfaz adaptable a diferentes dispositivos
- **Sistema Local**: Operación con servidor local para minimizar dependencia de internet
- **Sostenible**: Optimizado para bajo consumo energético y hardware existente

## 🛠 Stack Tecnológico

### Backend
- **Framework**: ASP.NET Core
- **Lenguaje**: C#
- **Base de Datos**: SQL Server Express
- **ORM**: Entity Framework Core

### Frontend
- **UI**: Razor Pages
- **Estilos**: CSS3 con diseño responsive
- **JavaScript**: Para interactividad

### Herramientas de Desarrollo
- **IDE**: Visual Studio Community
- **Control de Versiones**: Git
- **Plataforma**: .NET 8

## 📊 Métricas de Evaluación

El sistema será evaluado mediante:
- Reducción del tiempo de registro de asistencia y citas (meta: ≥40%)
- Disminución de errores manuales (meta: ≥80%)
- Eliminación de superposición de citas (meta: ≥95%)
- Satisfacción del personal (encuestas SUS y Likert)
